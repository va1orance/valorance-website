This demo supports OpenRouter. Requests go directly from your browser to its fixed HTTPS endpoint; there is no Learneth API proxy.

Check availability and pricing in your OpenRouter account. No fallback model or automatic retries.

Create a restricted key in OpenRouter ↗

Use a disposable key with a small credit limit. Never use a shared or privileged key. Revoke it in OpenRouter when finished.

What leaves this page, and what stays?

Your key is sent only as an Authorization header to OpenRouter. Your material, goal and session conversation are sent for each turn. The website writes no key, notes or conversation to cookies, browser storage, databases or URLs, and uses no analytics or third-party scripts.

OpenRouter and the selected model provider receive the request and may retain it under their policies. This is not a zero-retention guarantee. Requests ask OpenRouter to exclude providers that collect data or train on prompts; a model without an eligible route will fail rather than relax that setting.

Reloading, leaving, or “End & clear” clears the page's session state. Browser extensions, password managers, developer tools, and a compromised device can still access what you enter. JavaScript cannot guarantee secure memory erasure. The hosting provider may retain normal page-access logs, but keys and notes are never placed in page requests.

Each turn sends the session history to your provider.

Up to 20 model requests per session; 1,200 output tokens per request. These are usage limits, not a spending guarantee. There are no automatic retries. Clear before starting another session.
